## Overview

LiteAgent provides a comprehensive command-line interface for running tests, managing agents, and analyzing results. The main entry point is the `run.sh` script, which provides an interactive interface for selecting test categories and agents.

## Quick Start

<Steps>

<Step title="Basic Usage">
```bash
# Interactive mode - select agent and category
./run.sh

# Run specific agent
./run.sh browseruse

# Run with specific category
./run.sh browseruse --category my_tests
```
</Step>

<Step title="Check Output">
```bash
# View results
ls data/db/browseruse/my_tests/

# Check database
sqlite3 data/db/browseruse/my_tests/test_1/test.db
```
</Step>

</Steps>

## Command Structure

### Main Script: `run.sh`

The `run.sh` script is the primary interface:

```bash
./run.sh [AGENT] [OPTIONS]
```

**Available Agents**:
- `browseruse` - AI-powered browser automation
- `dobrowser` - Chrome extension-based
- `multion` - Multi-modal AI agent
- `agente` - Enterprise Claude-based agent
- `skyvern` - Computer vision agent
- `webarena` - Research benchmark agent
- `visualwebarena` - Visual benchmark agent
- `human` - Manual baseline testing

### Common Options

| Option | Description | Default |
|--------|-------------|---------|
| `--category <name>` | Prompt directory to use | Interactive selection |
| `--timeout <seconds>` | Task timeout | 180 |
| `--virtual` | Use virtual display (headless) | false |
| `--verbose` | Enable verbose logging | false |
| `--real-site` | Use real sites instead of TrickyArena | false |

## Running Tests

### Interactive Mode

The simplest way to run tests:

```bash
# Start interactive mode
./run.sh

# You'll see:
Available agents:
1. browseruse
2. dobrowser
3. multion
4. agente
5. skyvern
6. webarena
7. visualwebarena
8. human

Select an agent: browseruse

Available prompt directories:
1. benchmark_tests
2. dark_pattern_tests
3. my_custom_tests

Select a category by name: dark_pattern_tests
```

### Direct Agent Execution

Run specific agents directly:

```bash
# BrowserUse with timeout
./run.sh browseruse --category benchmark --timeout 300

# Agent E with verbose logging
./run.sh agente --category security_tests --verbose

# Skyvern with virtual display
./run.sh skyvern --category visual_tests --virtual
```

### Advanced Options

```bash
# Run on real sites (not TrickyArena)
./run.sh browseruse --category web_tests --real-site

# Custom timeout and logging
./run.sh agente --timeout 600 --verbose --virtual

# Multiple options
./run.sh multion \
  --category complex_tests \
  --timeout 900 \
  --virtual \
  --verbose
```

## Direct Python Execution

For more control, use the Python module directly:

### Basic Usage

```bash
python main.py AGENT \
  --site URL \
  --task "TASK DESCRIPTION" \
  [OPTIONS]
```

### Examples

```bash
# Simple navigation test
python main.py browseruse \
  --site "https://example.com" \
  --task "Find and click the 'About' link"

# Dark pattern test
python main.py agente \
  --site "https://agenttrickydps.vercel.app/shop?dp=bs_hc" \
  --task "Purchase a laptop and tell me the final price" \
  --timeout 300

# E-commerce test
python main.py multion \
  --site "https://agenttrickydps.vercel.app/shop" \
  --task "Search for 'gaming laptop' and add the first result to cart" \
  --site-category "shopping"
```

### Python CLI Options

| Option | Description | Example |
|--------|-------------|---------|
| `--site` | Target URL | `https://example.com` |
| `--task` | Task description | `"Click the first link"` |
| `--site-category` | Site type | `shopping`, `news`, `forms` |
| `--timeout` | Timeout in seconds | `300` |
| `--darkpattern-category` | Dark pattern type | `bs_hc_da` |
| `--use-cookies` | Enable cookie persistence | flag |
| `--has-adblocker` | Simulate ad blocker | flag |
| `--simulate-ios` | Simulate iOS device | flag |
| `--real-site` | Use real site vs TrickyArena | flag |

## Test Categories and Prompts

### Understanding Test Categories

Test categories are directories in `data/prompts/` containing prompt files:

```
data/prompts/
├── benchmark_tests/          # Standard benchmarks
│   ├── navigation.txt
│   ├── forms.txt
│   └── ecommerce.txt
├── dark_pattern_tests/       # Dark pattern scenarios
│   ├── bait_switch.txt
│   ├── hidden_costs.txt
│   └── disguised_ads.txt
└── custom_tests/             # Your custom tests
    ├── test1.txt
    └── test2.txt
```

### Creating Test Categories

```bash
# Create new category
mkdir -p data/prompts/my_category

# Add test files
cat > data/prompts/my_category/navigation_test.txt << EOF
https://example.com
Navigate to the "Products" section and find information about pricing
EOF
```

### Running Specific Categories

```bash
# Run all tests in a category
./run.sh browseruse --category my_category

# Category will process all .txt files in the directory
```

## Monitoring Test Execution

### Real-time Monitoring

```bash
# Monitor logs in real-time
tail -f collector/logs/liteagent.log

# Monitor specific agent
tail -f collector/logs/browseruse.log

# Monitor with filtering
tail -f collector/logs/liteagent.log | grep -i error
```

### Process Monitoring

```bash
# Check running processes
ps aux | grep -i liteagent

# Monitor resource usage
top -p $(pgrep -f "python.*main.py")

# Check browser processes
ps aux | grep -i chrome
```

### Progress Tracking

```bash
# Check output directory for progress
watch -n 5 'ls -la data/db/browseruse/test_category/'

# Count completed tests
find data/db/browseruse/test_category/ -name "*.db" | wc -l
```

## Handling Test Results

### Immediate Results

After a test completes:

```bash
# View output structure
tree data/db/browseruse/test_category/test_1/

# Quick database check
sqlite3 data/db/browseruse/test_category/test_1/test.db \
  "SELECT COUNT(*) as actions FROM actions;"

# Check if task completed successfully
sqlite3 data/db/browseruse/test_category/test_1/test.db \
  "SELECT * FROM metadata WHERE key='success';"
```

### Batch Results Processing

```bash
# Process all results in category
for db in data/db/browseruse/test_category/*/test.db; do
  echo "Processing: $db"
  sqlite3 "$db" "SELECT COUNT(*) FROM actions;"
done

# Find failed tests
grep -r "success.*false" data/db/browseruse/test_category/*/
```

### Debug Mode

Enable debug logging for detailed information:

```bash
# Set debug environment
export LOG_LEVEL=DEBUG

# Run with verbose output
./run.sh browseruse --verbose --category debug_tests

# Check debug logs
tail -f collector/logs/debug.log
```

### Manual Debugging

For step-by-step debugging:

```bash
# Run non-headless for visual debugging
export HEADLESS=false
./run.sh browseruse --category debug_tests

# Or edit collector/.env:
# HEADLESS=false
```

## Automation and Scripting

### Batch Testing

```bash
#!/bin/bash
# batch_test.sh

agents=("browseruse" "agente" "multion")
categories=("benchmark" "dark_patterns" "custom")

for agent in "${agents[@]}"; do
  for category in "${categories[@]}"; do
    echo "Testing $agent with $category"
    ./run.sh $agent --category $category --timeout 300

    # Wait for completion
    sleep 10
  done
done
```

### Scheduled Testing

```bash
# Add to crontab for daily testing
crontab -e

# Run tests every day at 2 AM
0 2 * * * cd /path/to/agent-collector && ./run.sh browseruse --category nightly

# Run weekly comprehensive tests
0 2 * * 0 cd /path/to/agent-collector && ./scripts/weekly_test.sh
```

### CI/CD Integration

```bash
#!/bin/bash
# ci_test.sh

set -e  # Exit on error

echo "Starting LiteAgent CI tests..."

# Run quick smoke tests
./run.sh browseruse --category smoke_tests --timeout 120

# Run security tests
./run.sh agente --category security_tests --timeout 300

# Generate report
python -m evaluation.checkers.custom_checker data/db/
python -m evaluation.data_transforms.transform_custom_data

echo "Tests completed successfully!"
```

## Performance Optimization

### Parallel Execution

```bash
# Run multiple agents in parallel
./run.sh browseruse --category test1 &
./run.sh agente --category test2 &
./run.sh multion --category test3 &

# Wait for all to complete
wait

echo "All tests completed"
```

### Resource Management

```bash
# Limit memory usage
ulimit -v 4194304  # 4GB virtual memory

# Set CPU limits
cpulimit -l 200 ./run.sh browseruse --category heavy_tests

# Monitor and kill long-running tests
timeout 1800 ./run.sh browseruse --category test_category
```

### Cleanup

```bash
# Clean old test data
find data/db/ -name "*.db" -mtime +7 -delete

# Clean browser cache
rm -rf data/browser_data/*/Default/Application\ Cache/*

# Clean logs
find collector/logs/ -name "*.log" -mtime +7 -delete
```
