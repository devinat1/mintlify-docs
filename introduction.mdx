## Overview

LiteAgent is a comprehensive testing and evaluation framework specifically designed to assess the safety and robustness of web automation agents when they encounter deceptive user interface patterns, commonly known as dark patterns.

## The Problem

As AI-powered web agents become more prevalent in automating online tasks, they face the same manipulative design patterns that affect human users—and sometimes they're even more susceptible. Dark patterns can:

- Trick agents into unintended actions
- Manipulate decision-making processes
- Exploit agent behaviors for malicious purposes
- Cause agents to fail tasks or produce incorrect results

## How LiteAgent Helps

LiteAgent provides a controlled testing environment where you can:

### 1. Test Multiple Agents
Evaluate different web automation agents using the same test scenarios, enabling direct comparison of their resilience to dark patterns.

### 2. Measure Performance
Track detailed metrics including:
- **Task Success Rate (TSR)**: How often agents complete intended tasks
- **Dark Pattern Susceptibility Rate (DPSR)**: How often agents fall for deceptive patterns
- **Confusion Matrix**: Detailed breakdown of success/failure scenarios

### 3. Collect Comprehensive Data
For each test run, LiteAgent captures:
- Complete interaction logs in SQLite databases
- Video recordings of agent behavior
- HTML snapshots at each step
- rrweb session recordings for playback
- Detailed traces for debugging

### 4. Automate Evaluation
Built-in evaluation suite automatically:
- Validates task completion
- Detects dark pattern interactions
- Generates statistical reports
- Creates visualizations of results

## Architecture Overview

LiteAgent consists of three main components:

<Tabs>
  <Tab title="Collector">
    The **Collector** module orchestrates agent execution:
    - Manages different agent implementations
    - Controls browser automation
    - Records interactions and captures data
    - Handles timeouts and error recovery
  </Tab>

  <Tab title="Evaluation">
    The **Evaluation** module analyzes collected data:
    - Runs custom checkers for task validation
    - Detects dark pattern susceptibility
    - Generates metrics and statistics
    - Creates tables and visualizations
  </Tab>

  <Tab title="TrickyArena">
    The **TrickyArena** test bed provides:
    - Six different website categories
    - Configurable dark patterns
    - Controlled testing environment
    - Reproducible test scenarios
  </Tab>
</Tabs>

## Supported Dark Patterns

LiteAgent tests agents against various deceptive patterns including:

- **Bait and Switch**: Promising one outcome but delivering another
- **Disguised Ads**: Advertisements disguised as content or navigation
- **Forced Continuity**: Making it difficult to cancel subscriptions
- **Hidden Costs**: Revealing additional charges only at final steps
- **Misdirection**: Using visual design to direct attention away from important information
- **Price Comparison Prevention**: Making it difficult to compare prices
- **Roach Motel**: Easy to get into a situation, hard to get out
- **Sneak into Basket**: Adding additional items without clear consent

## Key Benefits

- **Standardized Testing**: Consistent test environment across all agents
- **Comprehensive Metrics**: Detailed performance and safety measurements
- **Extensible Framework**: Easy to add new agents or test scenarios
- **Open Source**: Community-driven development and transparency
- **Docker Support**: Easy deployment and parallel execution
- **Rich Data Collection**: Multiple formats for analysis and debugging
